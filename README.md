# LiteTranslate 轻量翻译

> 只翻你眼前看得见的那部分。

一个**不卡、不乱**的浏览器翻译扩展。翻网页文字，也翻图片里的字。

---

## 它跟别的翻译方式有什么不同

它的做法是「**你滚到哪、就翻到哪**」：

- 页面不用等全部翻完才显示 —— 长网页也不会一开就卡
- 没滚到的部分不处理 —— 省时间，也省 API 费用
- 译文默认插在原文下方 —— 原文还在，对不上时一眼能对照

---

## 功能

### 翻网页文字

- **整页翻译**：译文插在段落下方，滚到哪翻到哪
- **自动翻译**：打开外网页面自动开始，不用每次点
- **只翻选中的**：选中一段 → 右键 → 翻译
- **手动翻译**：漏翻的内容粘进面板，单独翻
- **两种显示**：双语对照 / 直接替换
- **两种力度**：
  - `精翻` — 只翻成段的正文，跳过按钮和标签，译文干净
  - `全翻译` — 能翻的都翻，连 `Sign in`、`Password` 也翻（适合英语零基础）

### 翻图片里的字

- **右键翻译图片** — 真图、背景图、canvas 都认
- **自动翻译** — 图片滚进屏幕就翻，看漫画不用一张张点
- **截图翻译** — 框住屏幕任意区域，什么都能翻（视频画面、跨域图片都行）
- 译文贴在图片下方，不遮挡画面

### 引擎

| 引擎 | 说明 |
|---|---|
| **MyMemory** | 免注册，装上就能用（默认） |
| **硅基流动** | 免费、快，且**唯一支持看图的引擎**（推荐） |
| **智谱 GLM** | 免费，需 Key |
| **DeepSeek** | 收费，质量最好 |
| **谷歌** | 无需 Key，但需能访问 |
| **自定义** | 任意 OpenAI 兼容接口 |

### 界面

- 三套皮肤：极简白 / 深色科技 / 圆润可爱
- 自定义面板底色、背景图、文字颜色

## 安装

### 方式一：下载 zip（最简单）

1. 点右上角 `Code` → `Download ZIP`
2. 解压到任意文件夹
3. 打开浏览器扩展页：
   - Edge：`edge://extensions`
   - Chrome：`chrome://extensions`
4. 打开「**开发人员模式**」
5. 点「**加载解压缩的扩展**」→ 选中解压后的文件夹

### 方式二：git clone

```bash
git clone https://github.com/Kateyygs/lite-translate.git
```

然后在扩展页「加载解压缩的扩展」选中 `lite-translate` 文件夹。

---

## 使用

1. 点浏览器工具栏里的插件图标
2. 选「翻译范围」→「整页翻译」
3. 点「**开始翻译本页**」

**想看图片翻译**：右下角切到「漫画模式」，右键图片或点「📷 截图翻译」。

**更详细的说明**：面板 →「设」→「📖 功能介绍」

---

## 隐私

**不收集任何数据。**

- 不记录你访问了哪些网页
- 不上传统计信息
- API Key、设置项只存在**你自己浏览器的本地存储**
- 只有你主动点翻译时，待翻的那段文字才会发给你选定的翻译服务
